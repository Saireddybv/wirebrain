A diary that remembers with you.
Keep using ChatGPT and Claude as you normally would. While recording is on, Wirebrain saves supported text conversations on this computer and keeps each chat together.
Use the calendar to revisit a day, the star to keep a memory close, and the note beside your timeline to add your own thoughts.
You can pause recording at any time. Your diary remains here to read and search.
This is an early version. Check important memories against the original chat. Other apps, voice, and attachments are not fully supported yet.


ON YOUR COMPUTER
Make yourself at home.
1. Keep your conversations
First-time setup needs your approval to trust Wirebrain’s local certificate and route supported AI traffic. Recording can be paused at any time.
Show device setup command
Run this from the installed Wirebrain environment. On macOS, system network permissions may be required. After an unexpected shutdown, run wirebrain capture-reset before resuming.
2. Bring your history
Import a Wirebrain export, ChatGPT conversations.json, or Claude conversations.json. Text stays here. Maximum file size: 7 MB. Re-importing the same file skips duplicate moments.
3. Add optional local AI
Start with a small local search model (about 70 MB plus runtime dependencies). It finds memories by meaning without a large language model.
Install Ollama ↗ and download an embedding model for search and a writing model for answers. Downloads need internet; processing uses your local Ollama service. No provider keys.
For example, in an Ollama terminal: ollama pull embeddinggemma and ollama pull qwen3:4b. Model downloads and memory requirements vary.
Once enabled, new memories are indexed in the background every minute while the diary runs. Use Update memory index to catch up now.

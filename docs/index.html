A little space of your own

Your diary stays on your device.

Wirebrain stores conversations in a local SQLite database. You can import chat history or opt into capture for supported sessions. Local search and writing models are optional; the diary works without a provider API key.

The archive is not encrypted. Existing-session capture uses a local HTTPS proxy and requires your explicit permission to trust a certificate and change proxy settings. Support varies by app and provider protocol.

A few steps to begin

Start your AI memory diary.

  1. Install Python 3.11 or newer. Then download Wirebrain and extract the folder.
  2. Open a terminal in that folder. Run the source launcher:
    python start_wirebrain.py
  3. Open your diary. The launcher installs dependencies and opens the local dashboard. Import your history, or choose whether to enable supported-session capture.

Windows: you can also run Start-Wirebrain.ps1. macOS: run bash Start-Wirebrain.command. This is a source launcher, not a signed desktop installer. The first setup needs internet access. Live capture on macOS is not yet verified.

A few common questions.

What is local AI memory?

It is a searchable record of your AI conversations stored on your own device. Wirebrain helps you find past decisions, reuse useful answers, and bring context into a new session.

Do I need ChatGPT or Claude API keys?

No provider API key is needed for history imports or supported existing-session capture. Wirebrain also has a separate optional API gateway for people who want it.

Does it capture every AI app?

No. Capture depends on supported provider protocols and whether the app uses your local proxy. Some apps bypass proxies or reject locally trusted certificates. Check the capture guide before enabling it.

Can I search without a local LLM?

Yes. Keyword search works without a model. Semantic search can use a small local CPU embedding model; generated answers and reflections optionally use a separate Ollama writing model.

Is Wirebrain free and open source?

Yes. The code is available under the MIT license. You can inspect it, run it locally, and contribute through GitHub.

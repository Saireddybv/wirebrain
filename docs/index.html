Stored locally. Shared deliberately.

Your memory.
Your say.

Conversations live in a SQLite archive on your device. Keyword search and original-source tools work without an LLM. Optional local models add search by meaning and source-linked writing.

Capture is your choice. Existing-session recording uses a local HTTPS proxy and requires permission to trust a certificate and change proxy settings.

Sharing is a separate step. Connected assistants and the optional ChatGPT sign-in testing backend may send selected context to their providers. The archive itself is not encrypted by Wirebrain.

Install Python 3.11 or newer. Download Wirebrain, then start your diary.

  1. 1
    Get the source.

    Download the repository and extract it, or clone it from GitHub.

  2. 2
    Run the launcher.

    Open a terminal in that folder and run:

    python start_wirebrain.py
  3. 3
    Open your diary.

    The launcher prepares the environment and opens your local dashboard. Choose supported-session capture or import your history.

First setup needs internet access. Windows and macOS source launchers are included; actual macOS capture is still unverified. Linux can run the diary, imports, and MCP. This is an experimental source project, not a signed desktop installer.

A few things to know.

Do I need provider API keys?

No keys are required for the diary, imports, or supported existing-session capture. Optional local AI models run on your computer. The separate ChatGPT sign-in testing backend uses your own eligible Codex login and sends selected context to OpenAI.

Does it capture every AI app?

No. Capture depends on supported text protocols and whether the app uses the configured proxy. Voice, image/file contents, WhatsApp, Facebook, Instagram, and X-embedded Grok are not comprehensively covered. See the coverage guide.

Is this the same as ChatGPT or Claude saved memory?

No. Wirebrain builds its own source-linked memory from captured or imported chats. It does not read a provider's private saved-memory store or automatically inject context into every conversation.

Can an assistant read my whole diary?

You can connect MCP with all-collection access or restrict it to one collection. HTTP connections support revocation. Retrieved text may be shared with the connected assistant's provider. Unconnected apps cannot use these tools automatically.

Is Wirebrain free and open source?

Yes. The code is available under the MIT license. Run it locally, inspect it, and contribute through GitHub. Local models need suitable hardware, and optional third-party services have their own access requirements.
